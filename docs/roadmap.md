# Roadmap

Priority order; none of these items are implemented unless listed in the root README.

## Next

1. Validate native skill loading on current Claude Code and OpenCode releases; add only host-specific metadata or examples that official docs and runtime checks support.
2. Decide a compatibility/versioning policy and minimum supported Python version for the validator.
3. Select a specific Roblox Studio MCP candidate only after maintainer, implementation, permissions, and maintenance review; document tested capabilities without calling it official absent Roblox evidence.

## Later

- Add specialist workflows for Luau engineering, architecture, debugging, performance, security, UI, and testing when each has clear boundaries and value.
- Add host-native agent artifacts and plugin packages after manually validating formats and install behavior.
- Expand validator coverage only for deterministic project conventions that deliver actionable diagnostics.
- Establish release automation and compatibility matrix after scope and maintenance ownership are defined.

## Explicitly out of scope

A standalone AI app, chatbot, SaaS dashboard, Roblox game, replacement MCP server, automatic permission broadening, and unapproved publishing actions.
